# GdeiAssistant

广东第二师范学院校园助手社区开源项目集合，覆盖校园生活服务、信息查询与多端客户端实现。

## 仓库索引

| 仓库 | 说明 |
| --- | --- |
| [GdeiAssistant](https://github.com/GdeiAssistant/GdeiAssistant) | Spring Boot 4 + Vue 3 服务端与网页端 Monorepo |
| [GdeiAssistant-Android](https://github.com/GdeiAssistant/GdeiAssistant-Android) | Jetpack Compose + Material 3 原生 Android 客户端 |
| [GdeiAssistant-iOS](https://github.com/GdeiAssistant/GdeiAssistant-iOS) | SwiftUI 原生 iOS 客户端 |
| [GdeiAssistant-WechatApp](https://github.com/GdeiAssistant/GdeiAssistant-WechatApp) | 微信小程序客户端 |

## 参与贡献

提交 Issue 或 Pull Request 前请先阅读 [CONTRIBUTING.md](https://github.com/GdeiAssistant/.github/blob/main/CONTRIBUTING.md) 与 [SECURITY.md](https://github.com/GdeiAssistant/.github/blob/main/SECURITY.md)，不要发布真实账号、学校内部凭据或他人个人信息。
